# PET-Saúde Clima · Demonstração

Simulação navegável do registro de frequência mensal, com identidade visual do projeto e dados fictícios.

- Experimente os perfis de estudante e responsável.
- Registre e edite atividades fictícias, simule o envio, devolva para correção e valide a ficha.
- Consulte o relatório e use a impressão do navegador para salvar um PDF de demonstração.

**As assinaturas são simuladas e não têm validade oficial.** Nenhum registro é enviado ao projeto. As alterações ficam somente na sessão do navegador. Não utilize dados reais ou informações de pacientes.

A marca é utilizada na demonstração autorizada do projeto. A fonte Alte Haas Grotesk acompanha sua licença original em assets/fonts/.

Publicação pelo GitHub Pages, a partir de main e da pasta raiz. Este repositório contém apenas a simulação estática, sem banco, senhas ou servidor do sistema oficial.
